當沖大富翁　離線閱讀與歷史復盤
========================

交易練習已全面改用有來源的真實歷史 K 線，請連線至 https://rich.yilutek.com/morning 並登入教室。
真實分鐘資料由伺服器依練習進度揭露，離線包不包含完整行情，也不再啟動合成情境或模擬撮合。
離線版保留使用說明、固定委託示例及此裝置已保存的舊版復盤，不提供班級帳號、雲端同步或講師後台。

Windows：解壓縮整包資料夾，雙擊 START.bat。不需管理員權限或額外安裝。
Mac / Linux：需有 Python 3，終端機執行 bash START.command 或 bash START.sh。
所有伺服器只監聽 127.0.0.1:18765，不會提供區域網路或外部存取。
關閉啟動視窗即可停止；若提示連接埠已使用，請關閉先前的離線教室視窗。

請勿直接打開 app/index.html；瀏覽器模組需要透過 START 啟動的本機網址。
說明書與授權頁可在本機閱讀；外部來源連結需網路。
舊版戰績與復盤保存在此瀏覽器的 localStorage，清除瀏覽資料會遺失，不會自動同步。
不同電腦／瀏覽器／port 的紀錄各自獨立，課堂建議固定使用同一台電腦與瀏覽器。
