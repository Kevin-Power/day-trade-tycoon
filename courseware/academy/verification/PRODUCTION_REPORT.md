## 3. 內容結構

- 每個任務都有固定十個部分：目標、為什麼、準備、真實畫面（標號）、逐步操作、預期結果、遇到問題、自我檢查、想一想、下一步。每個任務只處理一個重要操作：LEVEL 01–06 的 34 個任務與期末任務簡報各 3–7 步（只有 3 個是 7 步），期末另有評量方式、計畫單、決策日誌、期末報告 4 頁表單。
- 術語在第一次出現的任務裡解釋（買一／賣一、市價／限價、委託／成交、張數／股數、庫存／未實現損益、手續費／交易稅等），書末術語表標示第一次出現的位置。
- 成就章是講義上的學習標記（First Quote、Market Reading、First Order、First Fill、Risk Awareness、Trading Review、Final Mission），由學員勾選、講師簽名，不是系統雲端徽章。每關結尾的鼓勵語都描述「已經會做的事」，沒有獲利承諾。
- 學員版的期末任務只有規則、時間安排、證據要求與四個評量面向（操作正確性 25、紀律 30、風險理解 20、復盤品質 25）；示範紀錄、評分細項與優秀報告範例只在講師版。

## 4. 設計

- A4 直式、白底內頁（只有封面與真實截圖是深色），固定頁首頁尾、七格進度條、筆記欄與填寫表格，適合列印也適合螢幕閱讀。
- 字型：Noto Sans TC（400／500／700／900 四個靜態字重，依實際用字做子集）＋ IBM Plex Mono（數字、時間、價格）。PDF 內為標準 CID 字型，中文可選取、可搜尋。
- 截圖標號：圓形步驟編號與框線是向量疊加，局部放大是同一張截圖的裁切。大多數標號依擷取時記錄的元素座標定位，重新擷取時會跟著元素移動；少數手動量測的位置（例如某一根 K 棒、清單中的某一列）在系統畫面改變後需要再檢查。每張圖說都註明「系統實際畫面 · 交易日 · 回放時間」。
- 封面圖是 10/06 五檔教材股票 09:00–10:30 的實際分鐘收盤漲跌幅（藍線為台積電），不是裝飾圖。

## 5. 驗證方式

每一項都由腳本實際執行，結果寫在 `verification/ACCEPTANCE.md`（自動產生）與同資料夾的 JSON 紀錄。

1. **逐關操作驗證（Playwright）**：`capture/run.mjs` 啟動本機暫存教室（`scripts/qa/desk-server.mjs`：臨時 PGlite 資料庫、只綁 127.0.0.1），使用教室主機目前上線 release 的程式（唯讀）與行情資料的唯讀複本。全新學員從入場頁開始，依講義順序走完 L01–L06 與期末任務；每一步都檢查畫面文字與系統狀態（例如「委託已送出 · 等待撮合」、成交價、手續費、本輪損益），同時擷取截圖與元素座標。
2. **版面溢出**：`build/pdf.mjs` 列印前逐頁量測，任何一頁內容超出 A4 版心就拒絕輸出 PDF，並列出頁碼。
3. **PDF 品質**：`build/qa_pdf.py` 檢查每頁為 A4；只嵌入 Noto Sans TC 與 IBM Plex Mono（不得有 Type 3 或系統備援字型）；每頁有可選取文字、關鍵字可搜尋；截圖有效解析度至少 150 dpi；並輸出逐頁預覽圖。
4. **學員版不含期末答案**：`build/qa_leak.py` 比對兩本 PDF 的文字，講師版專用的參考紀錄、示範報告與評分細項不得出現在學員版。
5. **數位互動版**：`build/qa_web.mjs` 在 375、390、768、1280 寬度檢查每個頁面的水平溢出、破圖、翻頁、截圖放大與勾選保存。
6. **人工逐頁檢視**：學員版每一頁的預覽圖都看過，自我檢查時發現並修正的問題：
   - 標號壓住介面文字（例如「參考金額」「賣1」「委託價格」）：改放在截圖左側的留白欄或元素旁的空白處，共 30 多張圖。
   - 細長截圖（快訊列、狀態列）被拉成整頁寬，印刷解析度只有 65–110 dpi：縮回原比例，全部截圖 ≥150 dpi。
   - 封面圖說與 LEVEL 標籤重疊；SVG 文字退回系統細明體；全形空白被 Chrome 嵌成 Type 3 字型；完成頁的漸層被點陣化成 72 dpi：全部修正後重新檢查為 0 問題。
   - 課前暖身的範例截圖只拍到畫面上半（下半在視窗外）：改以整個區塊擷取。
   - 「右方表格」「左頁」等只在紙本成立的位置描述：改成直接寫表格名稱，數位版也通用。
   - 非介面文字被畫成按鈕樣式：統一改用『』；05-1 要求填表卻沒有空白表：新增「我的費稅門檻計算」；03-5 紀錄表缺列標題：補上「成交」「庫存」。

## 6. 製作期間發現的系統現況（給產品團隊）

這些是講義寫作時核對到、但本次**沒有修改**的系統現況；講義依實際畫面撰寫，並在講師版「系統限制」頁提醒講師。

1. 教室內的線上說明書（`src/components/manual-page.tsx`）寫著「舊版生成行情和閃電下單已停止提供」，但目前工作台有「教學模擬五檔」與「閃電即送」（`morning-order-book.tsx`）。10/06 教材的價格來源說明也寫著「沒有合成逐筆或五檔」（由 `scripts/prepare-morning-data.mjs` 產生），與工作台的教學模擬五檔不一致。建議更新這兩處文字。
2. 講師工作台只看得到舊版課程紀錄，看不到學員真實 K 早盤練習的計畫與復盤；講義改以學員畫面的完成卡與紙本紀錄作為評量證據。
3. 每個交易日只保留最新一輪；學員開始新一輪前要先抄寫結果（講義提供「練習紀錄表」）。
4. 只有 2026/10/05、10/06 兩個交易日；從第 3 輪起學員會重看同一天，講義與評分規準都改看程序、不看是否猜對。10/05 沒有「站上／跌破昨收」快訊。
5. 沒有自助重設密碼。
6. 原期末考（本金 500 萬、2 倍額度）屬已停用的生成情境，無法開啟。
7. 不顯示成交量與均價線；快訊列只顯示最新一則；回放不會自動平倉（保存復盤只會取消未成交委託）。

## 9. 系統更新後如何重新製作

見 `courseware/academy/README.md`「重新製作」：重新擷取（本次約 11 分鐘；失敗會指出哪一步與當時的畫面文字）→ 整理截圖 → 一鍵輸出三份成品 → PDF、外洩與數位版檢查 → 產生驗收紀錄。若教材交易日改變，L03–L04 的時間點（09:20、09:37）與期末參考紀錄需要依新資料重寫。
