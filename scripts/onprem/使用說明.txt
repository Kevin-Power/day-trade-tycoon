當沖大富翁：新版地端教室
======================

本包由目前專案重新建置，需要 Node.js 24 或相容的更新版本，不需要 npm install。
包含目前真實 K 線教室、2026/10/05 與 10/06 兩日共 900 根已核對分鐘 K、
六個練習主題、紙上委託、復盤、講師台、說明書與獨立帳號資料庫。
這些是固定歷史教材，不是今日即時行情；沒有實盤下單功能。

Windows 使用
------------
1. 解壓整個 DayTradeTycoon-OnPrem 資料夾到固定位置，不要直接從 ZIP 執行。
2. 安裝 Node.js 24 後，雙擊 START.bat。
3. 第一次輸入你要使用的管理講師 Email。這不會寄信，也不會自動建立帳號。
4. 等到「已就緒」後，用外部 Chrome 或 Edge 開 http://127.0.0.1:18787。
5. 打開 data/首次使用.txt，取得本包自動產生的入場碼與首次設定網址。
6. 輸入入場碼；首次設定頁由講師自己設定姓名及至少 10 字的密碼。
7. 後續用一般登入。學員自行註冊並填班級代碼 LOCAL，不會取得講師權限。

停止、備份與更新
----------------
- 在啟動視窗按 Enter，等「資料庫已正常關閉」及程式退出，再關視窗。
  不要直接關黑視窗或強制終止程序；斷電後仍須檢查資料。
- 停止後雙擊 BACKUP.bat。備份含私人資料，放在 backups/時間戳。
  只有含 backup-manifest.json 且 complete=true 的資料夾代表備份完成。
  備份與原資料在同一台電腦，請自行另存受保護的異地副本。
- data/config.json 保存登入簽章、入場碼與首次設定 token，不要分享或刪除。
  data/pglite 保存帳號、進度與復盤。重新解壓或更新時不要覆寫 data。
- 更新前停止並備份。新包解壓到另一個資料夾，再搬移自己的 data 副本；
  同一份教室只啟動一份。不要把線上正式站的資料或秘密混入此包。
- 本包不自動搬移舊版 ZIP 或線上站的帳號與戰績，兩者資料獨立。
- 不要修改 server/public；啟動會核對程式雜湊。修改程式請由原始碼重新建置。

網路與埠號
----------
固定綁定 127.0.0.1，只供同一台電腦使用，不需新增防火牆規則。
不提供修改成 0.0.0.0 的捷徑；多人跨機教室請使用原專案的 HTTPS 部署流程。
不會更動 rich.yilutek.com、Cloudflare Tunnel、排程或正式服務資料。
若 18787 已被其他程式使用，停止後修改 data/config.json 的 port 為未使用埠號；
啟動器會同步設定登入網址與監聽埠，不會自動停止其他程式。8790 為正式站保留。

Mac / Linux
-----------
在解壓後的資料夾執行 sh START.sh；停止方式相同。
備份：node launcher.mjs backup。此版實際驗收環境為 Windows 與外部 Chrome；
Mac/Linux 啟動腳本尚未在對應作業系統實測。

檢查程式完整性：node launcher.mjs check
入場、登入與保存均在本機完成；離線時仍可使用已包含的歷史教材。
