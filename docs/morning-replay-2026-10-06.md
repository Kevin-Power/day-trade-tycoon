# 真實早盤練習：第一份上線教材

入口 `/morning`，從教室大廳的「真實早盤練習」進入。既有生成行情課程保留。此頁需要教室入場、帳號登入及教學聲明；離線包不提供這份完整分鐘資料。

## 學員流程

1. 讀取 2026/10/06 課程的市場背景與規則。國際指數、加權指數、外資與融資融券均標明參考日期／單位。
2. 寫下盤勢看法、關注股票、觀察原因、進場及停損條件。開始後保留原計畫，供結束時對照。
3. 五檔股票同步逐分鐘前進。09:00–10:00 是主要教材，可延伸至 10:30。只顯示已完成分鐘；可暫停、手動前進或播放。
4. 使用模擬資金委託，觀察下一分鐘的模擬結果；也可以整場不交易。
5. 寫復盤並保存。持倉以最後已知收價估值；結束不捏造平倉成交。

## 模擬成交規則

起始資金 10,000,000 元；每筆 1–3 張、每張 1,000 股，僅買入與賣出已持股數。同時只接受一筆等待中的委託，可撤銷；下一個分鐘完成時，才以該分钟開盤價記錄教學成交。沒有使用分鐘高低價推測價格穿越順序，也沒有假造限價排隊、滑價與五檔。

買進前依目前已知收價檢查資金；若下一分鐘價格變動導致資金不足，拒絕該筆模擬成交。教材成本沿用原模擬器：買賣手續費各 0.0855%、每筆最低 20 元，賣出稅費 0.15%，逐筆四捨五入。這些是固定練習參數，不代表學員實際券商條件。

## 實作與維運

- `server/data/morning-2026-10-06.json` 僅由 server handler 載入。前端／SSR 初始 HTML／離線 ZIP 不攜带完整行情。
- `scripts/prepare-morning-data.mjs --check` 以保留來源雜湊、五日日期與 90 分鐘格點檢查產物；正式 build 包含此檢查。
- `scripts/verify-morning-build.mjs` 掃描公開產物及解壓離線 ZIP，攔截分鐘行情與研究原始資料誤入公開包。
- `GET /api/morning` 只讀目前登入者最新一局；不接受任意游標參數。`POST` 採嚴格 action schema，伺服器游標每次最多加一分鐘、最短一秒。
- `morning_sessions` 儲存原計畫、游標、模擬資金、委託及復盤；`morning_requests` 保留冪等操作編號。交易鎖、版本與 owner 檢查防止多分頁重複推進及越權。
- 課程 ID 包含資料雜湊前綴。未來修正來源或成交模型須使用新版本 ID，保留旧版資料供重現，不原地覆寫已上線版本。
- 部署沿用 `docs/self-hosting.md`：離線 build → 正式 build → immutable release → 隔離 HTTP／外部 Chrome → 正常停機 → 一致備份 → 切換入口 → 啟動 → 外網驗證。
