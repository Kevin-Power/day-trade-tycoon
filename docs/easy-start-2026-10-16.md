# 新手上手完成紀錄（好玩計畫 子專案 A）— 2026-10-17

依 `docs/superpowers/specs/2026-10-16-easy-start-design.md` 與計畫 `docs/superpowers/plans/2026-10-16-easy-start.md` 實作。尚未部署到正式站。

## 完成的功能

**訪客先玩**
- 通過入場碼後，練習頁自動建立訪客帳號（better-auth 匿名外掛）。帳號名稱是「訪客」，email 用不會寄出的 `guest.invalid`。
- 建立訪客需要入場碼：登入 API 路由本身就會檢查，`hooks.before` 再檢查一次。頻率上限是 10 分鐘 60 次。
- 訪客不建學員資料，所以不在講師的班級名單裡。訪客呼叫建立學員資料的伺服器函式，會被拒絕。
- 按下開始時同意教學聲明：
  - 計畫表的開始按鈕上方固定顯示聲明句。
  - `start` 帶 `guestTerms: true`，伺服器在同一個交易寫入 `guest_consents`。
  - 一般帳號帶這個欄位會被拒絕。
- 訪客提示列「目前是訪客，建立帳號才會保存練習與之後的連續天數」，附「建立帳號」與「換人練習」。
- 完成一輪後，最上方有「建立帳號，保存這次的練習」卡片，可以按「之後再說」收起。
- 建立或登入正式帳號時，在同一個交易裡：搬移練習紀錄、刪除重送紀錄、刪除訪客。
  - 正式帳號在同一天已有未完成的練習時，保留帳號那一輪，並用一次性提示告知學員。
  - 搬移失敗時不刪訪客，並提示學員告訴講師。
- 每次建立新訪客時，順便清除 30 天前、還沒轉成正式帳號的訪客，每次最多 200 筆。
- 登入頁支援 `next`（只接受站內路徑，也不能指回 `/login`）與 `mode=up`（直接打開註冊）。完成第二步後回到原本的練習頁。

**兩下開盤**
- 計畫一鍵範本：突破前高、回測平盤、先看不做，另有「自己寫」。預設選好「突破前高」，按鈕是「用這個計畫開始」。
- 沒有任何練習時，計畫表自動打開。
- 開始後自動前進一分鐘，露出 09:00；手機切到 K 線分頁。

**教練提示**
- 三步：看走勢圖、讓行情動起來、成交與庫存。目標元素會框亮。
- 手機與大字模式改指「下單」「庫存」分頁。
- 可以跳過，Esc 也會關閉；鍵盤焦點留在對話框內。
- 這台裝置看過就不再出現。大廳的「第一次使用？看新手教學」可以重看。

**大字與朗讀**
- 「長輩模式 開／關」改成「文字大小：標準｜大字」，全站說明文字改稱「大字模式」，功能不變。
- 朗讀提示：
  - 開關在完整版的頁首；預設關閉，第一次切到大字時會詢問一次。
  - 用設備內建的中文語音（優先 zh-TW）。沒有中文語音時開關反灰，並說明原因。
  - 只唸教練提示、成交通知、開始與完成；行情不唸。

**大廳**
- 最上方是「今天三件事」：選一個計畫、模擬練習、寫復盤。
  - 每一步標示完成或「現在」。
  - 只有一顆主要按鈕：開始今天的練習／繼續練習／寫復盤／再練一輪。
  - 全部完成時顯示「今天完成了，明天再來」。
- 原本的「進入模擬下單」改成外框樣式的次要按鈕。

**加到主畫面**
- 加入 192、512、maskable 512 與 Apple 180 的 PNG 圖示，由品牌標誌產生（`scripts/generate-icons.mjs`）。
- manifest 補上 `id`、`scope` 與圖示；頁首加上 iOS 需要的設定。
- service worker 只有 install 與 activate，不寫 `fetch` 處理，不快取任何東西。只在 HTTPS 正式站註冊。
- 大廳的安裝卡片：Android 有「安裝」按鈕；iPhone 顯示大字三步圖解。關閉後不再出現。

## 對規格的調整

照抄計畫「對規格的補充與調整」，以及執行時的決定：

1. 入場碼由登入 API 路由檢查，`hooks.before` 是第二道防線。
2. 由我們自己在搬移的交易裡刪除訪客（`disableDeleteAnonymousUser: true`）。搬移失敗時，紀錄不會遺失。
3. 文案改成指向標籤：「標『昨』的虛線」、「圖上標『前高』的虛線」。圖上兩條線都是黃色虛線，用顏色會分不清楚。
4. 今天三件事的第 3 步是「寫復盤」。到 10:00 或教材結尾時亮起「現在」。
5. 開始後自動露出 09:00，「播放」仍由學員自己按。
6. 教練提示只在第一次從計畫表開始後出現，或網址帶 `coach=1` 時出現。
7. 朗讀開關放在完整版的設定；精簡版只放「標準｜大字」。
8. `useCurrentUserState()` 與 `getSessionUser()` 把訪客當作未登入；訪客身分另外由 `guest` 欄位提供。
9. service worker 不寫 `fetch` 處理。
10. 30 天清理在單元測試驗證。
11. 執行時另外決定：
    - 「今天三件事」放在大廳最上方。放在原位置時，手機要往下捲才看得到。
    - 大廳深色頁首的「標準｜大字」選中狀態改成白底深字。原本淺藍底白字看不清楚；舊的「長輩模式 開」也有同樣的問題。
    - 朗讀的一次性詢問是畫面底部的卡片，避免在 320px 寬的交易畫面溢出。

## 部署注意

- 網站啟動時會自動執行遷移 `0008_anonymous_users.sql`：`"user"` 加上 `isAnonymous` 欄位，並新增 `guest_consents` 表。
- 照既有流程部署：停機、備份、切換、啟動、驗證。
- **回退**：
  - 新欄位與新表對舊版無害，可以直接把 `appEntry` 指回前一版。
  - 回退後，已建立的訪客帳號會留在資料庫裡，但舊版不會使用它們。
- **入場頁的同意勾選**：入場頁本來就要求勾選同意才能進入教室。訪客按下開始時的聲明，是在這之外再確認一次。
