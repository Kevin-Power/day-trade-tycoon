本文件供業主及講師準備招生、回覆詢問與人工入班。包含可改為招生頁的文案、作業流程及通知範本；目前尚未對外發布。所有「待填」欄位都須先取得業主的實際決定，不能直接帶著空欄上線或用於收款。

已具備的教學產品是講師帶班搭配模擬練習、五堂實作加期末考、首筆計畫與完整復盤。課程費用、日期、名額、公開聯絡方式及收款安排尚未由本文件設定。網站帳號與班級功能不等於報名或付費資格系統。

## 一頁招生文案

### 用手機一步一步練清楚每一筆交易

當沖大富翁以講師帶班、模擬操作與課後復盤，帶你練習看商品、核對張數、寫下進出場條件，再用成交紀錄檢查自己的決定。

習慣用手機、希望慢慢學會操作的學員，可以從第一課開始。介面提供手機分頁、較大的操作按鈕與逐步導覽；需要看清楚時可先暫停，準備好再繼續。年長學員不必先背熟整個盤面，先把一次下單、確認成交和平倉走清楚。

### 五堂實作和一場期末練習

| 課程 | 畫面上的課程名稱 | 這堂練什麼 |
| --- | --- | --- |
| 第 1 課 | 成本與第一槍 | 從一張開始，分清委託與成交，檢查價差扣除費稅後的結果。 |
| 第 2 課 | 不接飛刀 | 面對下跌情境，檢查是否向虧損方向加碼，以及如何結束部位。 |
| 第 3 課 | 停損紀律 | 事先說明離場條件，練習判斷失效時降低風險。 |
| 第 4 課 | 順勢抱單 | 對照持倉時間、出場理由與費稅，檢查是否依原先條件操作。 |
| 第 5 課 | 停利比停損難 | 先寫出停利條件，再對照回檔時的實際決定。 |
| 期末考 | 自己執行規則 | 獨立完成計畫、模擬操作與復盤，再和講師討論待改進的動作。 |

教材盤的分鐘數是模擬行情時間。實際上課日期、每堂長度與授課方式，請以本期課程安排為準。

### 每次練習留下三件事

- **下單前的計畫：** 記下第一筆進場條件、離場條件與自行設定的模擬虧損額度。這是討論用的紀錄，不是自動停損委託。
- **自己的操作紀錄：** 核對委託、成交、庫存、費稅及平倉結果，練習用證據說明操作。
- **下一次的改進：** 結算後回看原計畫與首筆委託。講師可另外留下「這次觀察」及「下次練習」，學員重新開啟自己的完整復盤，按「查看講師回饋」，再選一項可做到的改進。

第一筆委託成功送出後，計畫保留原樣，不能事後補改。已登入並成功儲存至教室主機的原始復盤，可由同班、完成驗證及授權的講師唯讀查看；講師回饋另行保存，不改動原紀錄與成績。網站不會自動通知，請依與講師約定的時間回到復盤讀取。單純開啟網站或建立帳號不代表已報名。

## 人工詢問到首次復盤的作業流程

開始使用前，業主先完成下方決策表並指派回覆、對帳與入班的負責人。講師另確認自己的正式帳號、驗證、教學聲明及班級權限可用，再安排學員正式上課。

| 步驟 | 負責角色及操作 | 完成證據及狀態 |
| --- | --- | --- |
| 1 接到詢問 | 招生負責人記下稱呼、學員選擇的回覆管道及聯絡資料，提供免費體驗與已確認的課程安排。只蒐集回覆所需資料。 | 建立人工詢問編號，狀態為「待確認方案」。詢問不是訂單，也不占用未約定的名額。 |
| 2 確認方案 | 向學員確認本期講師、日期、授課形式、實際時長、費用、包含項目、使用期間及取消退款安排；確認手機使用需求和入班準備。 | 留下學員確認的方案版本與回覆，才改為「待付款」。未決欄位先釐清，不先索取款項。 |
| 3 核對付款 | 對帳負責人從業主指定的收款端核對實際款項、金額及對應學員。學員回報的匯款時間或辨識資料只是核對線索，不能只憑截圖判定收到款項。 | 記下收款端交易參考、核對日期與核對人，狀態為「已核對付款」。有差額、重複款或無法對應時保持待核對並聯繫本人。 |
| 4 發送本人入班資料 | 招生負責人只向已核對且方案確認的本人傳送入班通知。從受控管道另外提供當期入場資料，不在公開招生頁或群組公告秘密。 | 記下發送日期及本人收件確認，狀態為「待完成帳號」。通知不代表軟體已建立付費權限。 |
| 5 本人完成帳號 | 學員使用自己的帳號，從「登入／建立帳號」或「完成班級資料」核對名稱及班級，親自閱讀並處理教學聲明。講師將本人帳號與人工報名紀錄配對。 | 本人可入教室、顯示正確姓名及班級；講師確認同一位學員，狀態為「已入班」。不索取或代設學員密碼。 |
| 6 完成首次復盤 | 按 [第一堂課教案](instructor-first-lesson.md) 帶領練習，讓學員結算後查看「已儲存至教室主機。」與「查看完整復盤」。講師在自己的同班名單開啟同一盤唯讀紀錄。 | 記下課程與復盤編號，狀態為「首次復盤已確認」。只有本機保存時記「待確認提交」，先保留原裝置，不改記已完成。 |
| 7 讀取首次講師回饋 | 講師在同一盤另填「這次觀察」及「下次練習」，按「儲存回饋給學員」並確認保存成功。於課堂告知學員重新開啟自己的同一份完整復盤，按「查看講師回饋」閱讀，再請學員說出下一次要練的一個動作。 | 人工記錄學員已讀取並能說明練習重點。網站沒有自動通知或自動已讀回條；原紀錄與成績不因新增回饋改變。讀不到時先核對同一帳號、復盤編號及回饋保存狀態，不記為已完成。 |

| 付費資格控制 | 本期是否接受人工名單與共用入場碼，或必須先建置逐人資格、席次及期限限制。 | 〈待填〉 |

業主填完後，先形成同一份確認版方案，再將一頁文案、詢問回覆、入班通知及台帳欄位同步成相同內容。收款與入班仍依上面的人工流程執行；新增網站詢問表、付款串接或付費資格控制時，須另有具體實作與驗證。
