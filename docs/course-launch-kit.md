# 當沖大富翁課程招生與入班準備包

本文件供業主及講師準備課程、人工入班與課後交付。2026-10-05 增加網站課程詢問與管理講師收件流程，發布與驗證依 `course-inquiries-2026-10-05.md`。此文件不代表已開班、已對外發布招生通知或已啟用收款。

目前採用講師帶班搭配模擬練習。首位管理講師已完成初始化，日常由正常登入入口進入，不重跑首次設定。業主尚無公開 LINE、電話或招生 Email，改由網站表單接受詢問，不公開管理帳號。課程費用、日期、名額及付款安排尚未定案；先前討論的價格僅是建議，不能直接作為售價對外使用。網站帳號及班級功能不是付費資格系統。

## 對外介紹基準

當沖大富翁用講師帶班、模擬操作與課後復盤，帶學員練習看商品、核對張數、寫下進出場條件，再用紀錄回看自己的決定。每次先練清楚一個動作，再選下一次的重點；條件沒有出現時，可以觀察而不送單。

介面支援手機、iPad／平板與桌機，並提供大字、長輩模式及模擬閃電下單。首次上課先確認學員看得清楚、按得到，再練核對委託與成交，不要求學員一開始就使用快速下單。

可先提供 [免費操作體驗](https://rich.yilutek.com/try)、[課程說明](https://rich.yilutek.com/license) 及 [課程與操作協助詢問](https://rich.yilutek.com/license#course-inquiry)。體驗與詢問不用帳號，不計正式成績，也不替學員完成報名。公開頁不填未定價格、日期或講師資歷。

## 網站詢問與管理

1. 學員填稱呼（可用暱稱）、電子信箱或電話擇一、使用裝置、操作協助與問題，閱讀並勾選資料使用同意後送出。看到「已收到」才是主機確認成功；結果不明時留在本頁按「重試確認這份詢問」，不要重新填一份。
2. 管理講師正常登入後，到「講師工作台」的「課程詢問」查看。可切換新的詢問、已處理及全部，每頁 20 筆；按「更新詢問」重新讀取。其他講師與學員看不到這個收件區。
3. 管理講師依本人選擇的方式自行處理。網站不寄信、不撥號、不自動通知；標記「已處理」只代表管理進度，不代表已聯絡、已報名或已付款，也可重新開啟。
4. 詢問保存在教室主機與受保護的備份，不放入班級練習 CSV，也不保存在表單 localStorage。草稿只在目前頁面；離開前有提醒。離線包僅提供正式站連結，不能離線送出。

上線時沒有自動刪除與查詢者自行刪除功能；保留期限、停止聯絡及刪除要求的人工處理仍需業主定案。不要為了騰空間清除詢問或備份；達到容量限制先由維運人員處理，畫面不會假稱送達。

所有委託均為模擬，不連接券商真實交易帳戶。富邦 API 是後續串接方向，目前不能列為已交付的實盤功能。模擬成績、練習足跡與講師回饋不代表獲利能力或未來報酬。

## 三階段、六組課程任務

名稱、順序、三個步驟與復盤提問以 [learning-path.ts 的 COURSE_PATH](../src/lib/game/learning-path.ts) 為共同來源。六組任務不是已承諾的六堂課；實際堂數、日期、每堂長度與講師回饋次數，由開課方案確認。

| 階段 | 課程任務 | 帶班時練的動作 |
| --- | --- | --- |
| 入門操作 | 第一筆有計畫的操作 | 先寫條件與張數；若決定送單，核對商品、方向、委託與成交，再查看結束時庫存。 |
| 風險紀律 | 下跌時保護部位 | 先確認有無持倉，再核對張數與原定出場條件；從復盤查看部位變化。 |
| 風險紀律 | 練習執行停損 | 對照原先出場條件、實際操作及剩餘庫存；沒有持倉不必為練習而進場。 |
| 風險紀律 | 練習耐心與出場 | 等待設定條件，說明持有或出場的理由，回看時間與成本。 |
| 自主練習 | 按計畫完成收尾 | 核對模擬時間、待成交委託與庫存，處理部位後再檢查剩餘張數。 |
| 自主練習 | 獨立完成一次復盤 | 自行完成觀察、核對與復盤，找出已做清楚的動作，選一項下次重點。 |

教材盤的分鐘數是模擬行情時間，不是授課時數。教材挑戰條件仍保留作復盤討論，但不因單盤損益或系統收盤處理，就認定學員已掌握操作。

## 帶班前確認清單

### 業主與營運準備

- [ ] 完成本期方案：實際講師、授課方式、日期、時長、名額、費用、教材與使用期間。
- [ ] 確認講師回饋方式、次數及學員提交期限，避免把「有回饋功能」當成無限制服務承諾。
- [ ] 確認付款、取消退款、延期缺課及上課協助方式，再形成一份可供學員確認的方案。
- [ ] 指定回覆詢問、對帳、入班與教學負責人；目前詢問由管理講師收件，不自動通知。確認查看收件區的頻率，不公開管理帳號或初始化資料。
- [ ] 保持服務主機開機、連網、使用者登入並避免休眠。執行 `scripts/hosting/host.ps1 status` 檢查本機，再從外網打開正式教室與體驗頁。
- [ ] 核對本次正式 release 的部署與外網驗收紀錄。工作樹完成或本機測試通過，不等於正式服務已更新。

### 講師與教室準備

- [ ] 使用已初始化的講師帳號正常登入，核對本班資料與講師權限；不要建立另一個管理帳號替代。
- [ ] 打開「講師工作台」，按「更新班級紀錄」，核對本人名單。輸入姓名與課程，確認能找到預定課堂要看的練習。
- [ ] 在「回饋紀錄」選「尚無講師回饋」，準備本次要回看的復盤。狀態未取得的紀錄不直接當成尚未回饋。
- [ ] 在「保存狀況」找「尚無保存紀錄」學員，先協助登入及提交；這個狀態不是缺課、沒練習或未繳費的證明。
- [ ] 開啟本次課卡，確認三個步驟及復盤提問。帶班目標選一項可觀察動作，不以要求下單次數代替學習。
- [ ] 以實際上課裝置確認字級、觸控、橫直向與網路。需要時先選大字或長輩模式，快速下單留待基本核對流程熟悉後再練。

## 人工入班到首次回饋的交付流程

開始前先有確認版課程方案，未定欄位不先收款。下表是人工作業，不是網站已自動完成的功能。

| 步驟 | 操作 | 可確認的完成證據 |
| --- | --- | --- |
| 1 接到詢問 | 管理講師查看網站「課程詢問」，依本人選擇的聯絡方式自行處理。必要安排未定時，明確告知仍在確認，目前不要求付款。 | 網站收到時間、原詢問與管理狀態。人工另記聯絡負責人及待確認方案；詢問不等於訂單或保留名額。 |
| 2 確認方案 | 向本人確認講師、授課方式、日期、時長、費用、交付範圍、使用期間及取消安排。 | 留下本人確認的方案版本及日期，再進入待付款流程。 |
| 3 核對款項 | 若採收費方案，由對帳負責人從業主指定收款端核對金額與本人。不要只憑學員截圖判定入帳。 | 收款端交易參考、核對人與核對時間。差額、重複或無法配對保持待核對。 |
| 4 私人交付入場資料 | 只向已完成方案及款項確認的本人傳送入班通知；實際入場資料透過受控私人管道另行提供。 | 通知日期與本人收件確認。此動作不表示網站已建立付費權限。 |
| 5 本人完成帳號 | 學員用自己的帳號完成班級資料，親自閱讀教學聲明。講師核對人工名單、姓名與班級。 | 本人可登入且班級正確。密碼由本人建立及保管，不要求回傳。 |
| 6 完成第一次練習 | 從「第一筆有計畫的操作」開始。寫計畫、觀察、按條件操作，結束後查看保存狀態。 | 畫面確認「已儲存至教室主機。」並可查看完整復盤。只有本機保存時，記為待確認提交並保留原裝置。 |
| 7 從主機找到同一盤 | 學員回首頁「我的學習」按「更新紀錄」；講師到工作台按「更新班級紀錄」，依姓名與課程找同一份紀錄。 | 核對相同的復盤編號、課程與結束時間，不能只憑總盤數增加判定。 |
| 8 講師留下具體回饋 | 開啟同一盤唯讀復盤，填「這次觀察」與「下次練習」，按「儲存回饋給學員」並確認成功。 | 新增回饋出現在該份復盤；原成交、計畫與成績不因回饋改變。 |
| 9 學員讀取並說明 | 學員在「我的學習」按「更新紀錄」，用「已有回饋」或「查看最近的講師回饋」開啟；必要時在復盤按「更新回饋」。 | 請本人說出講師指出的動作與下一次重點，人工記錄已確認。回饋筆數不是已讀回條。 |
| 10 帶著一項重點再練 | 在「下次只練一件事」選重點並保存；若要重練，讀過確認畫面後再開新盤。 | 本機保存成功，學員能說出下一次要練的動作。不把捨棄草稿或失敗保存記為完成。 |

講師目前不會收到網站自動通知，學員也沒有自動已讀回條。安排課堂或事先約定的時間更新紀錄與回饋；尚無回饋時，先回看自己的紀錄，不承諾即時回覆。

## 學習資料的範圍與例外處理

| 畫面／資料 | 範圍 | 操作注意 |
| --- | --- | --- |
| 我的學習：復盤清單 | 帳號已提交至教室主機的最近 40 盤，可在相同帳號跨裝置查看。 | 首先顯示部分卡片，可按「查看更多復盤」；最舊未列出不等於刪除。更新失敗先重試，不清除原資料。 |
| 我的學習：統計 | 「已儲存的練習」為主機累計總盤數；「練過的課程」與「已有回饋」只看最近 40 盤。 | 練過表示有保存紀錄，不是通過或熟練。近期清單外的舊回饋不計入這個最近範圍。 |
| 首頁操作足跡 | 目前裝置最近最多 30 份完整復盤。 | 缺少完整檔或舊欄位不補判已做到；與主機 40 盤清單、累計盤數不是同一範圍。 |
| 訪客／離線練習 | 原裝置與瀏覽器，沒有自動加入帳號。 | 要供講師查看，正式練習前先登入並於結束後核對主機保存狀態。 |
| 下次練習重點 | 保存在目前裝置與帳號，不跨裝置同步，也不直接提交講師。 | 可「只保存重點」。跨課重新選擇；保存失敗不開始新盤，未保存離頁按畫面確認。 |
| 講師回饋 | 附屬於指定復盤，另行保存。 | 更新回饋或重新開啟同一盤；讀不到時先核對登入帳號、復盤編號與保存結果。 |
| 講師工作台 | 本班主機已保存紀錄，可搜尋姓名、篩課程及回饋狀態。 | 待回饋不代表逾期。學生保存狀況要搭配課程篩選理解；CSV 匯出為全部載入的班級練習，不是當前畫面的篩選結果。 |

原始首筆計畫在第一次委託成功後保留，不事後補改成較好的結果。系統收盤處理、部分減碼、零成交觀察與尚有庫存，須依原紀錄說明，不能合併成「學員已完成自主平倉」。
