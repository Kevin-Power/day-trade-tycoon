# 波哥每日盤前與真實行情重播課程規格草案

2026-10-06。供業主、講師與開發者建立每日教材：先了解當天盤前背景，再用同一天 4～5 檔股票的 09:00～10:00 真實走勢練習判斷，最後對照講師解析。內容架構依使用者提供的波哥節目整理與先前表格照片；個別說法仍需對應當集原始內容。

本文件是待實作規格。現有教室已有模擬委託、江波圖、前後高比較、復盤與講師回饋；個股路徑仍由日開高低收配合大盤節奏生成。每日影片、小馬欄位、個股真實重播及完整 N 字教學規則尚未接入。見 [行情來源](source-recovery.md)、[前後高功能](swing-highs-2026-10-04.md) 與 [富邦串接規劃](broker-integration.md)。

## 每日課程內容

| 區塊 | 每天準備的內容 | 學員要練習的判斷 |
| --- | --- | --- |
| 開場 | 課程交易日、星期、當集錄音或影片與文字摘要。保留使用者提供的開場「Hello，大家早安」。 | 確認自己正在練哪一天，以及背景資訊截至何時。 |
| 國際市場 | 道瓊、那斯達克、S&P 500、費城半導體：對應美股交易日、漲跌資料、走勢解讀與快樂小馬位置。 | 找出講師認為偏強、偏弱或尚不明確的部分，說出依據。 |
| 台股與台指期 | 加權指數、台指期夜盤、講師關注的價位，以及盤前預期。預測與已發生行情分開呈現。 | 判斷價格結構是否支持自己的觀察方向。 |
| 籌碼 | 外資現貨買賣超、期貨淨部位及變化、融資與融券變化；融資維持率依當集表格補入。 | 觀察價格與籌碼是否一致，或存在分歧。 |
| 焦點族群與個股 | 當日題材、講師挑選理由、4～5 檔股票代號及名稱。 | 說明股票被選入的理由，並在重播中觀察理由是否仍成立。 |
| 復盤與收尾 | 講師事後解析、學員原始決策與下一次練習重點。保留結語「好好地享受交易，好好地享受生活」。 | 找出一項做對的動作與一項需要修正的動作。 |

「右手」呈現價格走勢與技術觀察；「左手」呈現籌碼及外資部位。「右手向上、左手拖累」作為講師對分歧的解讀，不寫成必然造成震盪的系統判定。市場數據、講師觀點、學員判斷使用不同欄位。

AI、Google TPU、V3 衛星、油價及使用者列舉的股票屬於題材與標的範例，不自動帶入任何交易日，也不作為當日推薦名單。目標價新聞可放在觀念教材，但不能變成系統預設出場價或課程答案。

金額與口數不可混用；外資期貨淨部位、未平倉部位與當日增減須依來源分別命名，另記涵蓋商品及正負號意義。空值顯示「未提供」，不能當成零或中性。

2026-10-06 使用者補充「快樂小馬上是 EMA11」，教材採 EMA11 作為快樂小馬參考線，「小馬上」對應價格在該參考線之上。11 為期數，不預設為 11 個交易日；盤前各市場及盤中圖表採用的 K 線週期、計算價格、以完成 K 線或盤中最新值判讀、起始歷史資料與初始值算法仍需確認。「小馬中」是否代表貼近參考線及其容許範圍也未定，不自行加入固定閾值或買賣訊號。

美股前一交易日、台指期夜盤所屬交易日及台灣課程交易日各自記錄；假日不以日期減一天直接配對。擷取時間不能代替當時公開時間。盤前區只使用截止時間前可取得的內容；較晚公布、事後修訂或無法確認當時是否可知的內容放到復盤區。

## 手機課程流程

1. **看背景。** 顯示可手動播放的影片或錄音、可放大的文字摘要，以及國際市場、右手價格、左手籌碼三組資訊。詳細表格可展開，不把所有數字擠在首頁。
2. **寫判斷。** 學員選擇自己的觀察方向或「還不確定」，補充理由、預計等待的條件與失效條件。盤前判斷隨開盤保存；後續修正另留時間紀錄。
3. **練看盤。** 同一天 4～5 檔共用一個時鐘，09:00 起逐步播放。切換股票不重置時間；暫停與速度變更作用於整盤。新手保留核對後送單，閃電模式沿用既有模擬標示。
4. **看復盤。** 到 10:00 或提早結束後，先保存當時決策、模擬成交及剩餘庫存，再揭示本課完整走勢與講師解析。提早離開不自動算完成。

手機與長輩模式一次聚焦一個步驟，重要狀態同時用文字與顏色表示。桌機與 iPad 可以並列背景及圖表，但顯示的資料時間必須相同。

## 真實重播與防止提前得知結果

背景用來解釋當時環境，不用來生成或改寫真實行情。先以可核對來源的歷史資料匯入完成一課，再擴充每日編課與富邦資料接入；行情取得與真實下單分開開發。

重播只釋出目前時間以前的資料。股票清單、圖表座標範圍、摘要、提示與價格欄位都不得預先透露當日完整高低收或後續轉折；未確認的前後高不能事先畫出。正式盲練的資料介面須依伺服器進度限制可讀區間，不能僅在前端藏起已下載的完整路徑。

講師若在盤後挑選典型案例，課程標示「事後選取的教學案例」；不聲稱是當天盤前就能挑中的標的。重練與已看過解析的紀錄也須分開標示，不能當作首次未知行情的表現。

只有分鐘資料時標示「分鐘行情重播」，不插值冒充逐筆成交；只有圖表截圖時不能當成完整行情來源。缺資料時呈現缺漏，不以生成行情補成真實紀錄。即使價格來自真實成交，學員的成交仍由模擬模型判定，沒有歷史委託簿就不宣稱重現當時排隊與可成交量。

## N 字訓練與成就回饋

N 字攻擊需先由講師定義適用週期、轉折與回檔條件、確認時點、進場條件、失效及出場條件，再建立示例與反例。現有前後高比較不等同完整 N 字規則。

規則確認前，由學員記下判斷、講師人工回饋，不自動判定 N 字成立或給買賣答案。規則確認後也只用當時已知資料判讀，不能以事後最高點反推最佳操作。

學習回饋分為看懂背景、等待條件、按計畫操作與完成復盤，並保留對應的學員紀錄或講師回饋。條件未到而觀望可以獲得具體肯定；不按下單次數或單次盈虧頒發技術熟練資格。現有課程評分保持原規則，新增評量需另行實作與驗證。

## 首課交付與驗收

首課以一個交易日、一份盤前影音與表格、4～5 檔股票及 09:00～10:00 行情串起完整流程。當日行情取得並完成資料核對後再發布重播；不把尚未發生的行情稱為可練習的真實教材。

- 講師可核對原片段、數值單位與資料日期，未確認內容不偽裝成完整數據。
- 同一時刻切換四至五檔股票，時鐘與可見範圍一致；前進、暫停及重新連線均不洩露未來資料。
- 隨機核對原始行情與畫面時間、價格，缺漏與資料粒度清楚標示。
- 學員原始判斷、修正、模擬委託與成交可回到相同時間點核對；講師回饋不改寫原紀錄。
- 首次練習、提早結束及看過解析後重練分別記錄；手機、iPad 與桌機完成同一教學流程。

接入點為課程選擇與 `Scenario`、`live-tape` 資料入口、行情引擎及既有復盤／講師回饋流程。需新增帶版本的每日教材、真實行情資料路徑及分階段讀取權限，不能只在現有投影行情卡片上加影片就視為完成。
