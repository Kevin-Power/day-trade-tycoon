## 改之前

- 手機「行情」頁有江波圖，報價區有「買進／賣出」兩格，但按下去會跳到「下單」頁，還要「核對」、「確認送出」，送出後才回到行情。
- 庫存只在報價區右上角三行小字（庫存 N 張／均 X／損益），圖上只有很小的買賣三角形，沒有成本線。

## 改了什麼

- **行情頁底部的下單列**（只在手機和大字版，貼在下方分頁列上面，捲動時也一直在）
  - 一排三樣：張數「－ N 張 ＋」（1–400）、紅色「買進 市價」、綠色「賣出 全部 N 張」。
  - 按一下「買進」就送出 N 張市價單，不換頁、不用核對。「賣出」一次賣掉這檔的全部庫存，按鈕上寫著有幾張；沒有庫存時寫「沒有庫存」，不能按。
  - 送出後，這一排換成左邊「撤回」、右邊「委託中 · 買進 鴻海 1 張 市價／已累計 0／1 張」。成交後換回按鈕，上方報價區寫庫存、成本、損益，分頁列「庫存」下面也有本輪損益。
  - 送出失敗時，那顆按鈕寫「未送出」4 秒，回放停下來。
  - 從下單列送出時，回放不會停（原本下單會把播放停掉），所以接著播就會成交。
  - 規則和「下單」頁一樣：一輪只能有一筆等待中的委託；這檔的自動停利／停損賣出中時兩個鍵都不能按（寫「自動停利中」）；錢不夠的買進不能按（寫「資金不足」）；用掉一半以上資金的買進要按第二次（第一次按後按鈕變「確認買進／大額 59%」，6 秒內再按才送出）。
  - 資金和大額的判斷，用「畫面上的最新成交」和「教室已揭露那分鐘的最後成交」兩者較高的價格算（教室用後者計價），所以教室會拒絕的買進，按鈕本來就不能按。
  - 防連點：下單列剛變化（剛出現「確認買進」、剛從委託中換回按鈕）的 0.6 秒內按了不算。快速連點兩下不會直接確認大額、也不會在成交那一刻按到「賣出」。
  - 「賣出」一筆最多 400 張（教室一筆委託的上限）；庫存超過時寫「400 張（共 410）」。
  - 「下單」分頁還在，限價、其他張數、五檔點價都在那裡。
- **江波圖上的庫存點位**
  - 有庫存時畫一條藍色實線「成本 1462.50」，和自動出場的「停利」（紅虛線）、「停損」（綠虛線）放在一起。標籤寫的是庫存的成本，不會被四捨五入成跳動單位（1462.50 不會變成 1463）。
  - 買進、賣出的三角形記號加大，加上深色外框，在線上看得清楚。
  - K 線模式也一樣畫。電腦版的圖也有成本線。
- **報價區**：原本的「買進 1460／賣出 1465」兩格（像按鈕）改成價格旁邊兩行小字「買價 1460／賣價 1465」，避免跟下單列的「買進」「賣出」搞混。報價區稍微壓緊，把下單列佔掉的高度還給江波圖。
- **用字**：報價區的庫存和成交提示原本寫「均 1785」，改成「成本 1785」。圖上的「均」是當天的均價線，同一個畫面不能有兩種「均」。

## 我做的判斷

- 「賣出」賣全部庫存，不用張數欄。理由：當沖課最常見的是買進後一次出場，自動出場也是賣全部；要部分賣出可以到「下單」頁。
- 大額（用掉一半以上資金）的買進要按兩次，資金不足直接不能按。理由：一鍵送出很快，這兩種情況照「下單」頁原本的規則擋。
- 小手機（320×568，四吋 iPhone SE 一代）上，下單列會佔掉圖的高度。驗收門檻從「圖至少露出 140px」改成「100px」（量的是下單列上方，不是分頁列上方）；這種螢幕上的下單列也比較薄（按鈕 44px），價格字小一點。往下捲一點，整張圖會在下單列上方完整出現。375×667 以上的手機仍照原本的 200／240px 門檻。
- 「撤回」放在左邊「－」的位置，不放在「賣出」的位置：連點撤回時如果剛好成交、下單列換回按鈕，手指落在「－」上，只會少一張，不會賣掉庫存。
- 從下單列送出的單，頂端不再出現「紙上委託已記錄…」那兩行提示（下單列自己寫委託中），免得把江波圖往下推。
