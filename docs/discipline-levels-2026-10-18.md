# 紀律等級、稱號與慶祝完成紀錄（好玩計畫 子專案 C）— 2026-10-18

依 `docs/superpowers/specs/2026-10-18-discipline-levels-design.md` 與計畫 `docs/superpowers/plans/2026-10-18-discipline-levels.md` 實作。使用者說「做起來」，沒有先回答問題；規格裡標「設計決定」的都是設計者的判斷，請使用者過目。**尚未合併、推送或部署。**

## 完成的功能

**計分**（`src/lib/discipline/score.ts`，純函式）
- 每次需要時從既有紀錄算出：每日一題作答（含題目的關鍵價位與結果），以及已完成的模擬練習。沒有新資料表，沒有遷移。
- 每日一題：完成作答 +10、說出理由 +5、眼力（判讀和走勢一致）+3。「猜錯但說了理由」15 分，高於「猜對沒說理由」13 分。
- 模擬練習：完成一輪並復盤 +15、只下計畫寫的那檔股票 +5、收盤前不留倉 +5；沒下單兩項都算。每個台北日期只算最好的一輪，重練不能刷分。
- 十個等級（新手學員 0 → 紀律大師 1800）、八個徽章；分數不會扣、等級不會掉、徽章拿到就永久保留。
- 眼力和揭曉頁「這題要學的」用同一個「做出後高」判斷（`brokeOut` 改為匯出共用）。

**慶祝**（每日一題揭曉、練習完成）
- 只有真的寫入作答或完成一輪的那一次請求，回應才帶 `celebration`；重送同一題、重送同一個完成操作都不會再慶祝。
- 卡片：這次拿到幾分與明細、等級進度條（從之前長到現在）、升級橫幅與鼓勵句、新徽章、「看我的紀律」、音效開關。只列拿到的項目，不顯示「答錯」或「眼力 0」。
- 同一天第二輪：「今天的練習分已經算過了」，不顯示 +0。
- 動畫只在沒有開「減少動態效果」時播放；卡片在頁面內，不擋下一步。
- 音效預設關閉；開關在大廳頁首（朗讀提示旁）與卡片上。開啟那一下先播一次讓學員知道聲音；之後只在拿分時播柔和的正弦音（拿分兩個音、升級四個音，都不到一秒）。
- 朗讀開啟時，在頁面自己的那句話（揭曉結論、「已保存」）之後唸「拿到 N 分」，升級時加唸新等級。

**畫面**
- 大廳「今天三件事」下方的等級列：等級、稱號、進度條、還差幾分、徽章數；點了進「我的紀律」。
- `/progress`「我的紀律」：等級與分數（紀律分、眼力分分開）、怎麼得分、八個徽章（取得日期或目前進度）、最近得分、等級表。
- 練習完成畫面的勾選項目改成和計分一致：「照計畫的股票操作」「收盤前不留倉」只在成立時顯示；原本永遠成立的「先觀察，再決定是否操作」拿掉了。

**介面**
- `GET /api/discipline`：和 `/api/daily` 相同的保護（入場碼、同源、頻率上限、需要登入或訪客）。
- `POST /api/daily` 與 `/api/morning` 的 `finish`：回應多一個 `celebration`。

## 我做的判斷（請過目）

- 分數即時計算、不存表：規則改了，舊分數會跟著變，所以規則只加不減。
- 計分數值、十個稱號、八個徽章、鼓勵句：見規格第 2–4 節。
- 眼力的定義跟揭曉頁一致：做出後高（含突破後收盤又跌回）選進場算一致；沒有做出後高選觀望或不追算一致。
- 練習日以這一輪開始的台北日期計。
- 全勤一週：那週發了 5 題就在第 5 題答完時拿到；遇到假日只發 4 題的週，要等那週過完（下週一）才給，避免週五的題還沒產生就先給、之後又不符合。
- 音效預設關閉：課堂上很多手機同時響會干擾，長輩也不喜歡突然出聲。
- 實作時的調整（都記在計畫的進度紀錄）：
  - 讀紀錄的函式放在 `src/lib/discipline/records.server.ts`，避免和練習模組互相引用。
  - 大廳等級列與「我的紀律」頁先做，慶祝卡片才能連過去。
  - 畫面檢查合併成一支 `scripts/qa/desk-discipline.mjs`。

## 獨立審查與修正

完成後請 Fable 5.1 審整個分支，結論是「修好後可以合併」，沒有嚴重問題。三個重要問題都修了，每個都先寫出會失敗的檢查再修：
- **朗讀時分數被結論句打斷**（我自己也在畫面檢查發現）：揭曉頁先唸的結論會清掉排在後面的「拿到 N 分」。改成等頁面自己的那句開始唸之後才排入。`desk-discipline` 用錄音替身檢查朗讀順序：修正前只剩結論句，修正後兩句都在。
- **「我的紀律」顯示「眼力分 0」**：違反「不顯示眼力 0 分」。眼力分改成拿到之後才出現。`desk-discipline` 新增「進場但沒有做出後高」的情境：修正前失敗，修正後通過。
- **計分出錯會擋住存檔**：舊題目資料若缺結果，原本會讓作答與完成練習都失敗。改成那一題照樣算作答分、不算眼力；慶祝計算出錯時只是不顯示慶祝，作答與練習照常保存。單元測試先紅後綠。

另外，手機寬度的大廳頁首放了「音效」會多一行、把今天的一題往下推，所以手機頁首不放，改放在「我的紀律」的等級卡上（慶祝卡片上也有）。

**輕微問題也全部修好**（使用者問「都優化了嗎？」之後）：
- 遇到假日只發 4 題的那週，「全勤一週」在那週結束後的下一次作答或練習時慶祝，而且只慶祝一次：用學員實際作答與存檔的時間判斷，不是題目日期。週一清晨 6 點前補答上週五的題，也不會重複慶祝。
- 每次送出只讀一次紀錄：存檔後讀，扣掉剛存的那一筆就是存檔前的狀態。
- 螢幕報讀：卡片裡有一個先出現、稍後才填入文字的報讀區塊，唸的內容和朗讀一樣（分數，升級時加上新等級）。
- 手機上大廳等級列把「徽章 n／8」放在進度說明下面，不再隱藏。
- 補上測試：同時送出兩次只存一筆、只慶祝一次；旁邊有讀不懂的舊紀錄時，完成練習照常慶祝；不在紀錄裡的作答不會出現「+0 分」的卡片。
- 第二次審查結論：「可以合併」。
