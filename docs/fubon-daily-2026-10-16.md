## 最終審查與修正

由未參與實作的審查者檢查整個分支，結論為「修正後可合併」。

**嚴重問題，已修正**
- 富邦尚未更新時抓到的不完整回應原本會被存起來重用，導致那一天永遠上架不了。
- 修正：
  - 檢查「成交值第一名的非處置股有 13:30 收盤 K 棒」之後，才存原始回應。
  - 每日模式在 16:30 以前不執行。
  - 補抓的日 K 驗證通過後才存證。

**重要問題，已修正**
- 未預期的錯誤會讓狀態停在「執行中」，現在一律記錄為失敗，最後一次會通知。
- 行情連線初始化失敗，現在視為登入錯誤。
- 搬移資料夾遇到 Windows 鎖定檔案時，短暫重試。
- 上架中途當掉時，開始執行時會補回總清單與原始存證。
- 「已完成」不再蓋掉講師卡片上的最近一次結果。
- 執行鎖在超過 2.5 小時，或程序已結束時，可以接手。
- 排程在用電池時也會執行。
- 錯誤訊息先遮蔽秘密再截斷。
- 日誌補上各步驟與耗時。
- 狀態檔或總清單損壞時，先移到旁邊另存，再重新開始。

**已確認不用修**：審查者擔心 SDK 遇到限流（429）與查無資料（404）時的錯誤格式。我唯讀查看 SDK 2.4.0 內含的 fugle-marketdata 原始碼後確認：HTTP 400 以上一律拋出帶 `status_code` 的例外，所以 429 與 404 的判斷正確。

**暫不處理的小問題**
- `--symbols ""` 會變成全市場補抓。
- 已上架的日期再用 `--symbols` 指定新股票時，只回「已完成」。
- 一直沒能上架的日期，暫存區不會被清掉。
- ctypes 呼叫沒有宣告參數型別。
- 安裝腳本的小細節（下載中斷的壓縮檔會被重用、重裝時沒用到版本清單、`-Force` 沒先檢查同名工作）。
