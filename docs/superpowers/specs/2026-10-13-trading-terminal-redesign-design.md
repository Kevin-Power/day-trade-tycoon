# 交易畫面改版設計（子專案 1：版面與質感）— 2026-10-13

## 背景與目標

使用者提供參考盤（`reef-umbra-forge-umbra.grok.me`）的桌機與手機截圖，認為「人家畫面很棒、逼真很多」，要求參考它讓 `/morning?panel=trade` 交易畫面更漂亮、更像專業看盤軟體，並且下單方便好用。

參考盤的外觀源自本專案舊版的生成行情介面（`src/components/terminal.tsx` 等，綁定 `useGame` 生成引擎）。該介面在 2026-10-06 停用（`docs/real-only-replay-2026-10-06.md`）。這次只借它的版面與視覺語言，不恢復生成行情。

**成功的樣子**：在 1366×900 與 1920×1080 的桌機上，交易畫面一屏呈現自選、大走勢圖、五檔、下單與庫存，視覺接近參考盤的專業看盤軟體；所有數字與標記仍來自真實分鐘 K 或明確標示的教學資料；下單規則與撮合結果完全不變。

## 已確認的決策

1. **資料原則**：只用真實與可推導的資料。不生成逐筆、不畫江波逐筆線、不顯示未核對單位的成交量。
2. **拆分**：本文件只涵蓋子專案 1「版面與質感」。子專案 2「加權指數小圖」（證交所真實 5 秒資料，依回放進度揭露）與子專案 3「成交量柱」（先核對單位與缺漏）之後各自設計。
3. **做法**：為交易畫面新建單一樣式層與一組設計變數，取代目前疊加的四層主題；同時調整版面骨架。不再往舊樣式上疊加。

## 範圍

**包含**：交易畫面的桌機、平板、手機與長輩模式版面；配色與字體；走勢圖（分時與 K 線）呈現；五檔與下單區呈現；頂部狀態列與提示列；推導快訊；預估來回費稅；1x/2x 播放。

**不包含**：
- 加權指數小圖、成交量柱、均價線（子專案 2、3）。
- 伺服器 API、撮合規則、資料檔、登入與部署機制的任何變更。
- 交易畫面以外的頁面（大廳、登入、手冊、講師頁）。
- 4x 以上播放（需調整伺服器節流 `MORNING_ADVANCE_INTERVAL`，不在本次範圍）。

## 設計

### 1. 桌機版面（≥1200px）

畫面高度固定為視窗高度（`100dvh`），整頁不捲動；各欄內容超出時在欄內捲動。由上而下：

- **狀態列（40px）**：品牌、教材交易日選單與課程名稱、回放時間與狀態（●09:27 已暫停）、本輪損益、可用資金、播放/暫停、+1 分、1x/2x、復盤、教材、長輩、返回大廳。取代目前的標頭、教材列、帳戶總覽列與播放列。尚未開始練習時，播放區改為「開始練習」按鈕。
- **提示列（28px）**：左側「教學」顯示本課練習主題的原則（`exercise.principle`，靜態教材）；右側「快訊」顯示最新一則推導事件（見第 6 節）。成交回饋、10:00 檢查點與課程結束提醒也在這一列出現；後兩者附原本的按鈕（現在寫復盤、延伸觀察至 10:30）。
- **三欄主區（其餘高度）**，比例約 21% / 55% / 24%：
  - **左欄・自選**：藍色標題列「自選報價 N」；每列為名稱、代號、大字價格、漲跌與漲跌幅、小走勢（真實已揭露分鐘收價，缺分鐘斷線、昨收虛線）。選取列以左側藍線與較亮底色標示。底部保留作戰計畫摘要。
  - **中欄・走勢**：標題列含商品名稱與代號、分時/K 線分頁、大字現價與漲跌；其下一行開高低昨；走勢圖佔滿剩餘高度（1366×900 下約 560px，目前約 180px）；底部固定約 180px 的庫存/委託/成交分頁，標題列另顯示帳戶估值與期初資金。
  - **右欄・五檔與下單**：見第 4 節。
- **移除或搬移**：
  - 「01 作戰計畫 → 02 看盤練習 → 03 保存復盤」步驟條移除，改由狀態列按鈕狀態表達。
  - 頁面底部三個折疊區（教材與練習、本輪作戰計畫、資料來源與使用說明）改為狀態列「教材」按鈕開啟的側邊面板，內容不變。
  - 資料誠實標示（教學模擬五檔、真實 1 分 K、紙上交易）保留，由整句說明改為小標籤；完整說明在教材面板。

### 2. 配色與字體

交易畫面只使用下列變數，不在元件樣式中寫死色碼。

| 變數用途 | 色碼 |
|---|---|
| 底色 | `#05080d` |
| 面板 | `#0b111b` |
| 標題列（純色，底線 `#2a5594`） | `#14305a` |
| 分隔線 | `#1c2636` |
| 主文字 | `#e6edf7` |
| 次要文字 | `#8a9bb6` |
| 上漲 | `#ff3b3b` |
| 下跌 | `#19d36b` |
| 昨收線 | `#e8c547` |
| 選取與強調 | `#3b8cff` |
| 快訊底色／文字 | `#3a0d12` ／ `#ff8a8a` |

- 價格顏色依相對昨收：高於紅、低於綠、平盤主文字色。
- 紅、綠與次要文字在面板底色上的對比皆大於 5:1。
- 數字一律 IBM Plex Mono（已自架）並使用等寬數字（`tabular-nums`）；中文 Noto Sans TC。
- 字級：主價格 28px、自選價格 24px、五檔 14px、表格 13px；可見文字最小 11px。
- 標題列使用純色而非漸層。交易畫面維持只有深色主題。結構性分隔線沿用 2x 螢幕的半像素規則。

### 3. 走勢圖

沿用 `TapeChart` 的 `presentation="terminal"`，在其上擴充；其他使用 `TapeChart` 的舊畫面維持原呈現。

- **分時**（取代「行情」分頁名稱）：分鐘收價折線；折線與昨收之間填半透明色，高於昨收為上漲色、低於為下跌色。時間軸固定為整個課程時段（09:00–10:30），未揭露部分留白。不使用階梯線，因為它會暗示該分鐘價格不變。
- **K 線**：紅漲綠跌實心 K 棒；固定顯示最近 60 分鐘、棒寬固定，不再把已揭露的 K 棒撐滿寬度。
- **共用**：
  - 左側價格座標、右側相對昨收漲跌幅（%）座標。
  - 參考線：昨收黃色虛線、開盤灰色點線、現價標籤（背景色依漲跌）。
  - 推導標記只用已揭露資料：已揭露範圍的最高與最低價標「高」「低」；前高依既有 `deriveSwingHighs`，在 `confirmedAt` 之後才顯示；使用者成交點以三角形標示。
  - 十字線讀值與方向鍵操作保留；像素對齊沿用 2026-10-12 的實作。
  - 不顯示均價線與成交量。

### 4. 五檔與下單區

下單規則全部不變：點賣價買進、點買價賣出；每筆 1–3 張；同時一筆待撮合；下一分鐘開盤價撮合；閃電即送；核對後送出；撤回委託。

- **五檔改為直式階梯**：賣 5 至賣 1、中間大字最新收價、買 1 至買 5。
  - 深度條佔滿整列寬度。
  - 價格依相對昨收著色；委買底條用上漲色系、委賣用下跌色系。
  - 中間加「委買 vs 委賣」比例條，由教學五檔模擬量計算，標示「教學模擬」。
  - 點價行為、鍵盤操作與讀屏標籤維持現狀。
- **下單區**（右欄下半），由上而下：
  - 標題列「模擬下單」與閃電開關。
  - 買進／賣出切換。
  - 市價／限價；限價時顯示上下一檔按鈕。
  - 張數加減與 1/2/3 張快捷。
  - 參考金額、**預估來回費稅**、可用資金。
  - 主按鈕「核對模擬買進 N 張」。
- 核對、送出、待撮合、撤回的流程與文案不變，只換樣式。
- **預估來回費稅**：以參考價計算 `2 × commission(金額) + round(金額 × DAYTRADE_TAX)`，與撮合引擎使用同一套費率（`src/lib/market/ticks.ts`：手續費 0.0855%、最低 20 元，當沖稅 0.15%），並註明「假設同價出場」。例：2580 元 1 張約 8,282 元。

### 5. 平板、手機與長輩模式

沿用既有 `useTerminalLayout` 的斷點（桌機 ≥1200、平板 768–1199、手機 <768、長輩模式另計）。

- **平板**：自選改為頂部一排可橫向捲動的報價列（名稱、大字價格、漲跌，點選切換商品）；下方兩欄，左為走勢圖與庫存區，右為五檔與下單區。
- **手機**：維持目前五個分頁（分時、K 線、自選、下單、庫存）與分頁式下單，只換為新樣式；頂部加精簡狀態列（時間、損益、播放）。點擊範圍至少 44px。
- **長輩模式**：維持現行單欄大字與至少 56px 的主要按鈕，換用新配色；閃電、核對、撤回行為不變。
- **教材面板**：手機為全螢幕面板，其他尺寸為側邊滑出。

### 6. 推導快訊

新模組 `src/lib/morning-alerts.ts` 為純函式，輸入為伺服器已揭露的狀態（`MorningState` 與目前 cursor），輸出依時間排序的事件。只使用已揭露資料，不得引用 cursor 之後的任何分鐘。

事件類型：
1. 使用者委託成交或撤回（來自 session 的成交與委託紀錄）。
2. 自選商品前高確認（`deriveSwingHighs`，事件時間為 `confirmedAt`）。
3. 自選商品分鐘收價由上穿越或跌破昨收。

提示列顯示最新一則與其時間。只有第 1 類（使用者自己的委託）以 `aria-live="polite"` 朗讀，避免干擾。

### 7. 播放速度

1x 為每 2 秒前進 1 分鐘（現行），2x 為每 1 秒前進 1 分鐘（等於伺服器下限 `MORNING_ADVANCE_INTERVAL = 1000ms`）。純前端改動，自動暫停條件（10:00 檢查點、結束、分頁隱藏、版本衝突）維持現狀。

### 8. 樣式架構

- 新增單一樣式檔 `src/trading-desk.css`，以交易畫面根節點的專屬類別 `.trading-desk` 限定範圍，包含上述變數、版面與元件樣式。
- 目前作用於交易畫面的 `terminal-premium.css`、`terminal-polish.css`、`morning-flash.css`、`sim-order.css`、`quote-workspace.css` 中的規則，在新樣式涵蓋後移除。每個檔案移除前需確認沒有其他頁面使用其規則；仍被其他頁面使用的規則保留。
- 元件邏輯盡量不動；需要時才調整 JSX 結構（例如五檔改直式、狀態列合併）。

## 測試與驗收

1. **單元測試先行**：預估來回費稅、K 線 60 分鐘視窗、漲跌幅座標換算、推導快訊。快訊必須測「只用已揭露 K 棒」，例如前高在 `confirmedAt` 之前不得出現、cursor 之後的分鐘不得影響結果。
2. **既有檢查**：全部測試通過（目前 554 項）、`tsc --noEmit` 通過、`eslint src` 無錯誤、完整建置與離線版驗證通過。
3. **真實畫面驗收**（隔離環境：臨時 PGlite、本機埠、不碰正式站）：
   - 尺寸：1920×1080、1366×900、820×900、375×812、320×700，以及長輩模式（1366×900、320×700）。
   - 桌機 1200×800 以上整頁不捲動，走勢圖高度至少佔視窗 50%。
   - 所有尺寸無水平溢出、無文字截斷、可見文字最小 11px。
   - 圖表在 1x、1.25x、1.5x、2x 的抗鋸齒混色像素維持 0%。
4. **下單流程實測**：點價核對送出、閃電即送、撤回、賣出；每一步以 API 回讀現金、庫存與委託，確認與改版前規則一致。
5. **截圖對照**：每個尺寸保存改版前後截圖；1920×1080 與參考盤截圖並排。
6. **正式站驗收**：發布由使用者決定，依 `docs/deployment-2026-10-12.md` 的程序進行。發布後由使用者登入正式站，依提供的檢查清單操作一輪；不以使用者帳密代登入。

## 風險

- **改動面大**：版面骨架與多個樣式檔同時變動，平板、手機、長輩模式容易回歸。以每個尺寸的自動檢查與截圖對照控管。
- **舊樣式移除**：其他頁面可能依賴同名類別。逐檔確認後才移除。
- **共用圖表元件**：`TapeChart` 也被未路由的舊畫面使用；新呈現只在 `presentation="terminal"` 下啟用。
- **工作區共用**：另一個工作階段可能同時修改相同檔案；實作前檢查 `git status` 與檔案時間，小範圍提交。
