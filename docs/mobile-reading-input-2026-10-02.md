# 手機大字閱讀與數字輸入

本輪針對第一堂課的新生障礙延續 [第一筆計畫與講師復盤](first-trade-plan-2026-10-02.md)，並完成 [30 分鐘帶班教案](instructor-first-lesson.md)。

## 實際問題與修正

- 在 375 × 667、根字級 32px 的本機測試中，原導覽容器高 251px 且 overflow:hidden，「下一步」落在容器範圍之外。改為整張卡片可捲動，換步驟時回到開頭並聚焦標題；四步導覽及後續教學卡均可繼續。
- 同樣條件下，原結算頁標頭約 871px、頁尾約 534px，容器上限卻只有 603px，內容與操作被裁切。結算、設定、提示與計畫對話框改為完整捲動，結算先聚焦結果標題。窄螢幕結算數值單欄呈現，長標籤和結果可換行。
- 手機練習頁允許隨放大的上方文字長高，保留至少 320px 的練習區；頁面及練習區均可捲動，底部切換列保持可用。共用教學文字、輸入與按鈕字級改用相對單位。
- 首筆計畫漏填時，欄位標記 aria-invalid，顯示個別說明，焦點移到第一個未完成欄位。修正後再保存會移到下一個錯欄，已填內容保留。委託張數尚未完成時，計畫顯示「張數待完成」，不暗中保存舊張數。
- 委託張數／價格改用中央字串草稿，可先清空、輸入中間狀態、再完成。未完成時顯示說明、估算顯示「待完成輸入／—」，普通送出停用；中央 submit 也驗證草稿，因此閃電下單不能繞過而使用舊值。
- 快捷張數、加減、換商品、方向及五檔明確帶價同步對應草稿。市價不要求限價欄，切回限價會保留並驗證原草稿。平倉與既有風控保持可用；拒單不鎖第一筆計畫。

## 驗證與範圍

- 315 項測試通過，含新增 13 項中央草稿解析／真實 store-broker 測試；TypeScript、修改 TSX/TS 檔 ESLint、diff check 通過。
- 瀏覽器共用離線 UI：張數清空保持空白，送出停用；空白限價不能送出，切市價可送、切回限價仍空白且阻擋；`220.` 尚未完成，`220.5` 可用。
- 開啟閃電後，在空白張數下點五檔，顯示張數提示，委託／成交／庫存均維持 0。改選一張並關閉閃電後，市價買進成功，庫存一張；全部平倉與結算正常，保留兩筆成交。
- 根字級 32px 下已走完四步導覽、教學卡、設定開關、首筆計畫錯欄聚焦（進場→離場→額度）、有效保存、結算與完整復盤。375 × 360 短視窗亦可保存；此為短視窗測試，不冒稱實體手機鍵盤驗證。
- 大字結算容器 overflow:auto，clientHeight 601、scrollHeight 4894，scrollWidth 等於 clientWidth 301；可以捲至「查看完整復盤」並開啟。完整復盤頁 scrollWidth 等於 clientWidth 360。根字級 32px 的測試由只存在 tmp 的本機 HTTP fixture 提供，正式網站沒有插入測試樣式。
- 測試分頁 console errors 為空。截圖 `tmp/reading-large-text-error.png` 顯示大字情境下錯欄可見並取得焦點。
- 帶班教案以七個時段構成實際 30 分鐘，含問句、觀察證據、卡點處理及待補練紀錄，對照既有課程條件，不拿單盤獲利當作學會或實盤獲利證明。已核對現有按鈕名稱；新增數字草稿提示亦同步。

未進行實體手機系統大字、原生縮放、螢幕鍵盤或讀屏驗證，也尚無真實年長學員試教結果。32px 根字級與窄視窗證據不能取代這些驗收。
