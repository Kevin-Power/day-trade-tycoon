## 學員使用

- 教學卡主按鈕為「先看盤面，保持暫停」。收起後顯示模擬時間、可「再看這一步」或「繼續練習」；只有明確繼續才消費目前提示並恢復行情。切換盤面仍保持同一步，不會立即重彈。
- 初次導覽完成、但教學提示關閉時的準備卡，也能收起及重看。操作導覽所有步驟仍禁止交易與結算，測驗暫停時仍禁止送單或平倉；收起卡片不會繞過限制。
- 關閉教學提示保留當時的暫停狀態，不再意外恢復時間。收起或重看教學卡會解除閃電啟用並說明原因。
- 卡片標題接住鍵盤焦點；收起後焦點移至暫停區，明確繼續後回到上方時間控制。導覽切換頁面不再被背景盤面的延後聚焦蓋過。
- 卡片內 Escape 收起並保持暫停。Space 保留盤面暫停／繼續功能，忽略長按重複、組字及修飾鍵，不干擾按鈕、輸入欄、其他對話框與圖表。
- 原「快訊」改標「盤中練習」。三天 13 則固定提示與動態教材提示改為核對當下資料、計畫、委託、成交及庫存，不提前告知全日高低、收盤或最終成交額。數值行情、提示時間與順序維持原樣。

歷史教材目錄仍可查看完整日 OHLC，情境名稱仍保留歷史背景，不能把這項更新描述為盲測未知行情。撮合、費稅、原評分規則、帳號、學員復盤與真實券商狀態均未更動。

## 維運修補

- 只在收到 owned child 的退出事件後，才清除程序 handle；kill 請求成功不等於退出。
- 停止逾時仍保有原程序及 runtime ownership 並重試，不在舊 app 存活時讓第二個服務接手。保留原資料庫關閉 acknowledgment，未確認關閉的退出仍禁止備份。
- Windows 刪除 service lock 紀錄失敗時，服務保留 lease 重試，避免舊 supervisor 在新 owner 啟動後覆寫 state。備份的 maintenance lease 清理失敗則釋放後回報錯誤，避免命令掛住。
- 手動停止重試成功以 exit 0 結束；真正 supervisor failure 仍 exit 1，避免手動停止因暫時延遲而觸發排程自動重開。
- 健康檢查新增錯誤種類、耗時、HTTP 狀態與連續失敗數，不保存 URL、正文、headers 或原始錯誤字串。健康檢查及恢復門檻維持原值。

這些是已確認流程缺陷的修補；上一輪最初健康檢查失敗的根因仍沒有足夠證據。若作業系統持續不確認退出或無法寫入停止狀態，服務會持有 ownership 持續重試，需要主機診斷，不能宣稱所有當機或停機原因都已修好。
