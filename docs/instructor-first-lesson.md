# 手機學員第一堂課 30 分鐘帶班教案

這份教案供講師帶領第一次使用手機模擬教室的學員，完成一次從入場、寫計畫、核對委託到結算復盤的操作。對應大廳「開始第一課」及「第 1 課／第一筆有計畫的操作」，教材盤為「8/26 開盤觀察」。本課先確認學員能自己操作、說明理由與找到紀錄，再依觀察安排重練。

以下 30 分鐘是實際帶班時間。第一課的 30 分鐘則是模擬行情時間，會受暫停與倍速影響，兩者不能混用。可以提早按「結束練習」結算，但必須先處理庫存與未成交委託。

**本輪已部署：** 保存重點及重練確認、跨課重點、保存失敗與草稿離頁提醒已完成隔離瀏覽器驗證並部署，詳見 [驗證紀錄](practice-loop-2026-10-02.md)。真人及實體手機試教仍待執行。

## 課前準備

- 課前另留時間協助帳號與班級資料，避免把註冊擠進本堂 30 分鐘。學員自行建立密碼、閱讀並決定是否同意教學說明；講師不索取密碼，也不代替本人勾選。
- 講師備好教室網址、有效入場碼及已確認的班級代碼。正式繳交作業前，請學員從大廳「登入／建立帳號」或「完成班級資料」確認自己的名稱及班級。訪客或離線練習不會自動出現在講師後台。
- 講師帳號須完成驗證、教學聲明與主機授權，且和學員同班，才能查看已保存的完整復盤。先確認「講師工作區」可用；若尚未完成，改由學員在自己裝置展示，不宣稱紀錄已提交給講師。
- 用實際授課手機走一次流程，確認文字可讀、鍵盤可收起、內容能上下捲動。講師另備一個自己的示範盤，不使用學員帳號代下單。
- 建議先以每人都有手機的小班試教。全程一次只說一個動作，示範後等學員指到同一位置，再讓本人點按；不只用「紅色那個」指認買賣。

## 開場講稿

「今天練的是看清楚、按一次、查紀錄。這是教室模擬，不會送單到券商。教材包含歷史資料和教室生成資料，不是現在市場的逐筆行情。今天賺錢或賠錢都要留下原來的理由；不會用一盤成績證明你能在真實市場獲利。跟不上時先按『暫停』，我們等你。」

## 30 分鐘操作流程

### 第 0 到 3 分鐘 入場並辨識模擬

**帶法：** 學員在「教室入場碼」填入講師提供的代碼，讀完說明後自行操作，再按「進入教室」。已在大廳者核對自己的學員名稱。指出「所有委託皆為教室模擬」的說明，再按「開始第一課」。首頁若顯示「接續上次復盤」，可到「我的課程路線」按第 1 課的「進入課程」。

**講師問句：**「這裡的買進會送到哪裡？現在顯示的是誰的學習紀錄？」

**觀察點：** 學員能說出不會送到券商，並認得自己的帳號或明確知道正在使用訪客練習。只輸入入場碼不算登入個人帳號。

### 第 3 到 7 分鐘 認識商品和手機導覽

**帶法：** 第一次練習會出現四步「操作導覽」。逐步按「下一步」，讓學員指認下方的「自選行情」「走勢圖」「模擬下單」「庫存成交」。第一課預選鴻海 2317、一張；點商品與看圖不會送單。

按「完成導覽，準備練習」後，盤勢仍暫停。讀完開場教學提示，可先按「先看盤面，保持暫停」，讓學員找到商品與價格，再用「再看這一步」重讀提示。講師確認大家就緒才按「開始練習」或上方「繼續練習」。需要重看完整導覽者從「更多設定」按「重看操作導覽」。在「更多設定」將「練習速度」選為「1 倍」，關閉後仍保持暫停。後續教學卡同樣可先收起，準備好再按「繼續練習」。

先到「走勢圖」讀出商品名稱，辨認昨收及均價線；請學員描述畫面上的相對位置，不要求猜下一段走勢。到「模擬下單」確認商品為鴻海、方向為「買進」、張數為「1 張」。保留閃電下單關閉。

**講師問句：**「一張是多少股？現在只是看商品，還是已經送出委託？你在哪裡看到昨收？」

**觀察點：** 能唸出 2317 鴻海、買進、一張等於 1,000 股，並找到「暫停」。講師尚未要求送單。

### 第 7 到 12 分鐘 先留下第一筆計畫

**帶法：** 在「模擬下單」按「第一筆下單前，先寫計畫」。開啟後會暫停；先核對「這次準備」的商品、買賣方向與張數。讓學員用自己的話填三欄：

1. 「看到什麼條件，才會進場？」先說明想觀察的條件，再寫下來，例如本課正在練習的價格與昨收關係。這是待觀察的條件，不是保證有效的策略。
2. 「發生什麼情況，就要離場？」寫清楚自己判斷失效或結束本次練習的條件，避免只寫「看情況」。
3. 「這次自行設定的模擬虧損額度（元）」由學員提出大於零的討論額度，講師確認其理解；不要宣稱系統會把虧損鎖在這個數字。

按「保存計畫，回到委託」。確認入口變成「已記下計畫 · 可修改」，並再次核對張數。保存只暫存這一盤，結算才會隨復盤保存；未結算就重新整理會遺失。關閉後不會自動恢復行情。

**講師問句：**「你剛才寫的條件發生了嗎？如果沒有發生，你會怎麼做？填了虧損額度，系統會自動幫你平倉嗎？」

**觀察點：** 學員能說出自己的進場和離場條件，也知道這不是停損委託，不會自動平倉。第一筆委託成功送出後就鎖定，尚未成交或取消都不能事後改理由。

學員不填仍可練習，原紀錄會如實留白。講師註記需要補練「下單前說清楚理由」，不替學員填寫或事後補造計畫。若改了商品、方向或張數，首單送出前應重開計畫核對；原計畫不會跟著委託草稿自動改變。

### 第 12 到 18 分鐘 送一次並確認委託與成交

**帶法：** 按「繼續練習」觀察自己的條件。條件未出現可以空手，講師用自己的示範盤示範後續操作；不要為了趕流程要求學員違反原計畫。先講清楚「限價」有指定價格但可能等待成交，「市價」按當時模擬撮合，實際成交價可能和畫面估計不同。

準備送單的學員依序唸出商品、買進、一張、委託方式與價格，再按一次「送出買進」。首堂不使用閃電下單，也不連按送出。切換下方「庫存成交」，依序點「委託」「成交」「庫存」核對：

- **委託：** 尚未全部成交的指示。看「等待成交」或「部分成交」、「已成交」及「尚待成交」張數。取消時用「取消未成交部分」，已成交部分仍存在。
- **成交：** 已被模擬撮合的明細。核對商品、方向、張數、價格與費稅；最新一筆在最上方，一筆委託可能分成多筆成交。
- **庫存：** 現在還沒結清的部位。委託已全部成交時，委託清單可能是空的，仍要到成交與庫存確認，不能因此再送一次。

如果本次很快成交，講師用自己的示範盤說明未成交限價單；不要求每位學員為了看掛單而額外交易。若取消後要改單，先確認撤掉的未成交數量與現有庫存，再決定下一筆。

**講師問句：**「哪一個畫面證明已經成交？還有幾張在等待？如果只是取消委託，已買到的股票會一起不見嗎？」

送出後先一起讀「最近一次送出結果」。若因餘額或庫存不足等原因顯示「這次未建立委託」，請學員說出原因，並指出這次沒有新增委託與成交；不要把先前成功的紀錄誤認為本次結果，也不要連續重按。此提示只存在本盤，切換手機分頁仍可回看；離開、新盤或更換身分會清除，不是另外保存的拒單作業。

**觀察點：** 能指出實際成交明細和目前庫存，或正確指出仍在等待成交；沒有因為不確定而重複送單。只送出未成交委託，不記為完成買進操作。

### 第 18 到 22 分鐘 自行平倉並查餘額

**帶法：** 請學員說明原先離場條件與此刻是否相符。先「暫停」，查「委託」並取消不需要的未成交部分。到「模擬下單」確認仍選著鴻海，再按「平倉此檔」。回「庫存成交」查「庫存」與「成交」，確認本商品剩餘張數，並找出相對應的賣出成交。若還有部位，先查訊息及剩餘張數，不直接認定按過即清空。

再查「委託」確認沒有遺漏，避免剩餘委託之後又建立部位。第一課允許暫停中模擬下單及平倉，復盤會標記暫停中成交；這種練法不代表真實市場能暫停。已空手者說明沒有部位可平，講師記下此項仍需實作。首堂只練一檔及逐檔核對。

**講師問句：**「你按的是平倉還是取消未成交部分？哪裡能證明目前沒有持倉？還有沒有等待成交的單？」

**觀察點：** 能核對庫存為零、沒有待成交委託，並找到平倉成交。強制平倉或只看到按鈕反應，不算自行完成這一步。

### 第 22 到 25 分鐘 結算並確認保存

**帶法：** 庫存和未成交委託都處理好後，手機／長輩模式按上方「結束練習」；其他版面先展開「帳戶與練習設定」。確認框會先暫停並列出目前庫存與待單；仍要核對時選「返回盤面，保持暫停」，準備好才按「確認結束，查看復盤」。確認後會結束本盤並計算結果，不能再回到本盤繼續；直接「回大廳」不會替未結算的一盤留下作業。

在「練習已結算」畫面找「模擬淨損益」「費稅」及「最大回撤」，再讀下方保存訊息。看見「已儲存至教室主機。」才能記為已提交；「完整復盤已保存在這台裝置。」只表示本機保存。若顯示尚未保存或主機尚未保存，依提示保留頁面與紀錄，先由講師協助，不用重新整理碰碰運氣。

**講師問句：**「這個數字有沒有扣費稅？哪一行告訴你講師那邊已收到？」

**觀察點：** 能把損益和費稅分開指出，並說出目前是主機保存、本機保存，還是尚未保存。不能用「按了結束」代替保存確認。

### 第 25 到 30 分鐘 用紀錄說明並選一項改進

**帶法：** 按「查看完整復盤」。先核對本課與這次紀錄，再找「先前的計畫，和第一筆委託」，對照原商品、方向、張數、進場條件及首筆委託。首筆委託可能被取消或未成交；不要把它當成第一筆成交。往下看「完整成交紀錄」，用一筆進場和一筆平倉說明實際操作。

講師在「講師工作區」點開本班學員名稱，於「逐次練習復盤」找到同次紀錄，按「查看完整復盤」唯讀查看。若尚未取得該紀錄，讓學員在自己的裝置展示並查保存狀態，不借用其他學員帳號或改班級碼繞過。

學員在自己的復盤頁「下次只練一件事」選一項，按「保存重點並重練本課」。保存成功後會開啟「重練前，先看這個重點」，先唸一次自己的動作，再按「帶著這個重點開始」，才會開新盤。若本堂到此結束，可按「只保存重點」，不開始新盤。這個重點只保存在目前裝置與帳號，不會跨裝置同步或提交給講師；講師頁沒有代填入口。

若學員明確選擇略過保存，可按「不保存這次重點，先重練」，讀完「這次先重練，不保存重點」後，再按「不保存，開始重練」確認；未保存的新文字會捨棄，先前保存的提醒仍保留。不要把略過記為已保存。

換到另一課時不會預填前課重點，請為本課重新選擇。若保存失敗，畫面會保留選擇且不開新盤，先讀提示再重試。修改後切換頁面會看到「練習重點還沒保存」；要保留新內容就按「留在這頁保存」，確定捨棄才按「不保存，離開這頁」。

**講師問句：**「你的進場條件在哪一段紀錄看得到？離場是否照原先條件？這次最想保留或改進哪一個動作？」

**觀察點：** 學員能指出一筆實際操作和原計畫的關係，說出費稅的影響，再留下一個可執行的改進，例如「送出前先唸商品與張數」或「不確定時先查委託」。尚未成交者如實說明等待原因，不編造交易理由。

## 講師觀察紀錄

每項記「可獨立完成」「提示後完成」或「待補練」，並註記卡住的實際動作。這份觀察表不會改動系統成績，也不是正式能力認證。

| 觀察項目 | 可核對的證據 | 本次紀錄 |
| --- | --- | --- |
| 辨識模擬與商品 | 能說出不送券商，指出鴻海、一張與買進方向 |  |
| 先有計畫 | 首單前留下自己的條件，知道額度不會自動停損；留白則記待補練 |  |
| 委託和成交分清楚 | 指出實際狀態、已成交及尚待成交張數，沒有重複送單 |  |
| 自行平倉 | 找到平倉成交，核對零庫存及無待成交委託 |  |
| 結算及保存 | 正確區分主機保存、本機保存與未保存 |  |
| 復盤有根據 | 用原計畫及一筆成交說明，留下一項下次動作 |  |

系統第 1 課仍檢核「不攤平」「回撤 ≤ 2%」「收盤前自行平倉」「完成一筆獲利當沖」；獲利條件扣除分攤的進出費稅。本教案的操作觀察不替換這些條件。操作已看懂但獲利條件未達時，照實保留結果，再安排重練，不追加交易湊成通過。

若時間到但尚未完成，不加速催促手部操作。由講師協助核對庫存與委託，完成可確認的結算後註記待補練項目。條件未到而空手、未成交或只有觀摩，都不能填成已完成買進和平倉。

## 常見卡點與現場處理

| 學員遇到的情況 | 講師下一個動作 |
| --- | --- |
| 手機鍵盤遮住按鈕 | 先收起鍵盤，在表單內容區向上捲動；確認仍是原表單，不重新整理網站。 |
| 看不到「送出買進」或「平倉此檔」 | 先切到下方「模擬下單」，再捲動下單區；讓學員唸出按鈕文字，避免點到五檔。 |
| 計畫無法保存 | 看錯誤提示，確認兩個條件都有填寫且各不超過 200 字，模擬虧損額度大於零，張數為整數。不要略過訊息重按。 |
| 張數或價格尚未輸入完成 | 可以先清空再重打。看到「待完成輸入」時先補好欄位；一般及閃電下單均不會沿用舊數字送出。也可明確選擇快速張數或五檔價格，並再次核對。 |
| 計畫突然不能改 | 先查是否已有成功送出的第一筆委託；即使已取消也鎖定。保留原理由，在復盤說明調整，下次再先寫。 |
| 收起教學卡、關閉計畫或設定後行情不動 | 這是保持暫停的設計。全班就緒後按上方或教學卡內「繼續練習」；收起的卡片可用「再看這一步」重看。 |
| 出現「已掛出委託」但庫存沒增加 | 查「委託」的尚待成交張數與價格，再看「成交」。先確認原單，不再送一張試試看。 |
| 顯示「這次未建立委託」 | 先唸出商品、方向、張數與原因，再查目前委託及庫存；這次拒絕沒有新增委託，不要用上一筆成功成交代替本次結果。 |
| 委託顯示部分成交 | 說明已成交部分會留在庫存；「取消未成交部分」只取消剩下的張數。分別查兩邊。 |
| 看見賠錢就想加碼 | 先暫停，回看原離場條件與現有張數。本課練一張及查紀錄，不以多送單追回損益。 |
| 講師看不到這次紀錄 | 依序查學生原帳號、班級、教學聲明及主機保存訊息；再查講師同班、驗證與授權。若只有本機紀錄，就用原裝置展示。 |
| 重開後找不到未結算計畫 | 計畫未結算前只暫存在本盤，不能恢復就如實記錄遺失；不補造同一盤的首單前理由。 |

## 課後交付與下次安排

學員口頭或依講師既有作業方式交付：本課名稱、這次復盤編號、一筆操作的理由、一項下次改進。講師確認是同一盤且保存狀態清楚，再依觀察表決定補練導覽、委託判讀、平倉或成本；不要只看盈虧及班級排行。

線上教室的講師可從工作區開啟學員復盤，按「查看講師回饋」，填寫「這次觀察」與「下次練習」，再按「儲存回饋給學員」。前者引用本盤的一筆操作，後者只指定一個可觀察的動作。看到「回饋已儲存」才算完成；若尚未確認成功，保留原內容並按「重試確認這則回饋」。回饋送出後保留原文，修正或補充請新增一則。

學員用自己的帳號開啟已儲存到主機的同一份復盤，按「查看講師回饋」，唸出下次動作，再寫進自己的練習重點。依目前重練流程，依上方「保存重點並重練本課」的確認步驟開始下一盤。這不會自動寄信或推播；離線版與尚未同步的本機紀錄無法讀取線上講師回饋。回饋獨立保存，不改動原計畫、成交與課程條件。

課堂紀錄保留原始結果。手冊、教案與畫面都不承諾真實獲利，也不因完成本堂課就認定適合實際交易。
