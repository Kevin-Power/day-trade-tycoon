   - 庫存的參考損益。
   - 庫存分頁上的待成交筆數。

## 6. 第二輪精修（使用者要求「要做出精品」，2026-10-18）

- **安靜的控制項**：原本最搶眼的是實心藍色切換鈕（1x、標準、市價）和兩個疊在一起的紅色實心塊（買進方向鈕＋送單鈕）。
  - 改成淡色選取狀態，買進／賣出方向鈕改成酒紅／墨綠淡色。
  - 現在畫面上唯一的實心按鈕是「核對模擬買進／賣出」，報價重新成為視覺重點。
- **重播工具列**：播放、速度、+1 分、復盤合成一組，不再是一排各自有框的按鈕；播放中改成淡紅色，「開始練習」仍是實心。
- **品牌與細節**：
  - 品牌圖示放進小方塊；下單金額改成一個安靜的方框，參考金額 15px。
  - 自選選中列從左側強調線往右淡出。
- **圖表**：最新價紅色標籤不再半蓋住右側的百分比刻度（手機最明顯：2580 蓋住 +0.14%）。
- **手機底部分頁**：改成不透明，捲動時下面的文字不會透出來。
- **考慮過但沒有做**：工作包樣板用「卡片＋間距」的版面。這次沒有採用，原因有二：
  - 你的指令要的是 Bloomberg 密度、細框線、不要 SaaS 儀表板感。
  - 加間距會讓 1366×900 的走勢圖低於子專案 1 定的 700px。
