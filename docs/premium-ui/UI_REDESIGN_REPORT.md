## 4. 行為上的改變（都是畫面層）

1. **手機分頁從 5 個變 4 個**：
   - 分頁改成 自選／行情／下單／庫存，固定在底部。
   - 分時／K線變成「行情」頁內的切換。
2. **換股票時保留目前的分時／K線**：以前桌面點自選會強制切回 K 線。
3. **手機上方工具列只保留**：大廳、時間、標準／大字、教材、重播控制。
   - 交易日選單移到教材抽屜。
   - 本輪損益與可用資金移到「下單」與「庫存」頁。
4. **新增顯示**：
   - 買價／賣價（教學模擬）。
   - 庫存的參考損益。
   - 庫存分頁上的待成交筆數。
5. **大字模式在寬螢幕置中 760px**：以前拉滿整個螢幕寬度。
