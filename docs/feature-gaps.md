## 現況能賣什麼

已能開班的教室模擬：

- 全班同一組入場密碼（講師發、本機解鎖）
- 教材週凍結 2026/08/24–08/26，六課＋期末考
- 券商風格盤室：自選、江波／分時、五檔、委託單、庫存／委託／成交
- 模擬撮合：張數、漲跌停、費稅、收盤強平、教學暫停卡
- 閃電下單（#4）：點五檔可帶價或即送；期末考暫停中會 toast，不靜默
- 資料徽章（#3）：官方 vs 教室生成
- 線上「每日實盤」自由練習（交易日約 13:50 後抓完整盤）；地端包只內建教材週
- 戰績存在該機 `localStorage`，大廳有近況表與空狀態
- 說明書頁可列印／下載 PDF（`npm run build:manual-pdf` 從 `/manual` 重印）
- 盤中「回大廳」有庫存／未成交時會確認；未結算盤不入戰績、不自動平倉

明確**還沒有**、且不應對外宣稱的：

- 券商實盤下單（`/api/broker/order` 回 501；點「實盤」只 toast）
- 學員／講師分開帳號、席次、公開定價、繳費
- 班級排行、聊天、跨機戰績雲端同步

相鄰大 PR（**不要整包合進來**）：[#2 `grok/p0-p2-classroom`](https://github.com/Kevin-Power/day-trade-tycoon/pull/2) 已試作 email 帳號、`/teacher`、復盤頁、排行榜、22 檔 SSOT。那是另一條產品決策，不是本檔小修的範圍。

| ID | 缺口 | 現況 | 建議切法 |
